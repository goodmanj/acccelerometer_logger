This repo contains software and 3-d design files to allow you to build an accelerometer data logger based on the [Adafruit RP2040 Adalogger](https://learn.adafruit.com/adafruit-feather-rp2040-adalogger/) and [Adafruit MSA311 Triple Axis Accelerometer](https://www.adafruit.com/product/5309).  3-axis acceleration data is stored as a CSV file on the Adalogger's SD card.

This project includes 3-d design files for the case, assembly instructions, and CircuitPython code.

* [accelerometer_logger.py](accelerometer_logger.py): [CircuitPython](https://circuitpython.org/) code to control the data logger.
* [adalogger_case.3mf](adalogger_case.3mf): 3-d printing file for the case.  Intended for printing in PLA plastic on any common FDM printer.
* [adalogger_and_case.step](adalogger_and_case.step): 3-d design files for the project.  Can be edited in any full-featured CAD tool.
* Assembly instructions: coming soon!

See also the [original 3-d design files](https://cad.onshape.com/documents/e8a46c59dcb9122418c8d0ff/w/36be3dad887f7d9deae555c1/e/28ac3882d8a0cd794988601d?renderMode=0&uiState=6ae1c55c8a48d114163d88ae) created in [OnShape](https://www.onshape.com/en/).
